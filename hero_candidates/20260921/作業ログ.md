## OGP画像の差し替え（2026-09-21・りあさん指摘）

- `index.html` の `og:image` / `twitter:image` を新ファイルへ、`og:image:alt` を「Leer のキービジュアル — 虹色の光とガラスの欠片に囲まれた少女」に更新

- **注意**: X 側はページURL単位でカードをキャッシュする。すぐ反映されないときは Card Validator（https://cards-dev.twitter.com/validator）でURLを読み直させる

## OGPが古いまま出る件の切り分け（2026-09-21）

りあさん報告：素のURLで実際に投稿しても古い画（ナイモノネダリ）のまま。`?v=2` を付けたURLなら新しい画が出た。

**原因は X のカードキャッシュで確定。** サーバー側に古い画を指すものは一つも無いことを実測で確認済み：

- `og:image` / `twitter:image` は新ファイル1つだけ。`image_src` も JSON-LD も無し
- `src/worker.js` は HTML を書き換えていない（og・HTML を触る処理が0件）
- KV のコンテンツに OGP 設定は無い（キーは version/updatedAt/news/series/works/profile/links/savedAt）
- Twitterbot・facebookexternalhit を名乗って取得しても新しいタグが返る
- `index.html` の `Cache-Control` は既に `public, max-age=0, must-revalidate`（最短）。**X はこれを無視して独自にカードを保持している**
- 末尾スラッシュなしのURLはリダイレクトされず 200（別URLとして扱われるかは X 次第）

打った手：
- 旧 `ogp.jpg` の中身も新しい画に差し替え（新旧URLで md5 一致 `73cea6dc…`）。元のナイモノネダリ版は `.backup/ogp_naimononedari_20260921.jpg`
- `og:url` を削除。残っているとクエリ付きURLを正規URLへ丸めてキャッシュを引き続けるため

**X にカードキャッシュを消させる公式手段は無い**（Card Validator は廃止済み）。素のURLで新しい画にするには、キャッシュが切れる（おおむね1週間）のを待つしかない。ただし**投稿後の表示にクエリは出ない**ので実害はない（カードが生成されると本文のURLテキストは消え、ドメイン名だけが出る）。
